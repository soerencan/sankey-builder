# Repository guidance

- For setup, commands, and codebase orientation, consult the relevant sections of [README.md](README.md).
- For browser-facing changes, use the relevant checks in [VERIFICATION.md](VERIFICATION.md). Report what was checked and what remains unverified; do not append verification history to that document.
- Keep documentation specific to this project. Reference existing instructions instead of duplicating them. Do not add manual line wrapping in Markdown files.
- Use code comments to explain non-obvious constraints, trade-offs, design decisions, workarounds, or gotchas. Delete comments that restate the code.
